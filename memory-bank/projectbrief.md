# Project Brief

**Проект:** Многостраничный сайт-портфолио Олега Чумаченко (веб-дизайнер & продуктовый верстальщик).

## Цель
Объединить отдельные Next.js-проекты (главное портфолио + кейс-стади) в единый многостраничный сайт и разместить его на GitHub (GitHub Pages).

## Источники (исходные zip-архивы в корне репозитория)
- `portfolio.zip` — главное портфолио (тёмная тема «эспрессо & шампань»).
- `Scenario_v0_v0.zip` — кейс 01 «Адаптированный сценарий» (светлая «рукопись»: paper/ink/red).
- `pitch-presentation_case.zip` — кейс 02 «Мир кунфу» (светлая «галерея»: страница кейса сознательно отделена от тёмной презентации-продукта; питч-дек опубликован отдельно).
- `Titanik_v0_v1.zip` — кейс 03 «Titanic English» (светлая «кино»: navy + gold).

> Нумерация соответствует порядку карточек на главной после перестановки 23.08.2026 (яркостной баланс): сценарий → кунфу → Титаник.

## Ключевые требования
- Каждый кейс сохраняет свою уникальную визуальную тему.
- Навигация: карточки кейсов на главной → страницы кейсов; хидеры кейсов → назад на главную.
- Статический экспорт для хостинга на GitHub Pages.
