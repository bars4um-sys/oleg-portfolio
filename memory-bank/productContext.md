# Product Context

Сайт-портфолио демонстрирует услугу: превращение сухих программ/текстов в кинематографичные продающие лендинги для онлайн-школ и экспертных продуктов.

## Страницы
| Маршрут | Содержание | Тема |
| --- | --- | --- |
| `/` | Hero, избранные кейсы, об авторе, услуги, процесс, контакты | тёмная |
| `/scenario` | Кейс 01: из программы курса (.docx) → готовый лендинг course.kinomagica.ru | светлая «рукопись» |
| `/kunfu` | Кейс 02: инвест-питч-дек для медиа-экосистемы «Мир кунфу» (нарративная страница + ссылка на опубликованную презентацию) | светлая «галерея» — страница кейса сознательно не похожа на тёмную презентацию-продукт |
| `/titanic` | Кейс 03: редизайн лендинга «Titanic English» (до/после, бриф, метрики) | светлая «кино» |

> Порядок карточек на главной (светлая → тёмная → светлая) выровнен по яркости 23.08.2026: «Титаник» и «Мир кунфу» поменялись номерами (02/03).

## UX-цели
- Кинематографичная, премиальная подача.
- Тема каждого кейса работает на его сюжет (рукопись — для «сценария», киноафиша — для «Титаника»).
- Плавная навигация между главной и кейсами.
