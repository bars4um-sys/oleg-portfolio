## Эволюция решений
- Сначала пытался `onlyBuiltDependencies` в pnpm-workspace.yaml — не сработало (старое имя ключа в pnpm 11; нужно `allowBuilds`/`dangerouslyAllowAllBuilds`).
- Гипотеза про `CI=true` отвергнута (CI=0 не помогло); причина — pnpm `verifyDepsBeforeRun` + игнор build-скриптов.
- Изображения: PNG/JPG → WebP через `cwebp -q 82 -resize <w> 0`, ресайз только если исходник шире цели (без апскейла); неиспользуемые файлы удалялись.
- Нумерация СЦ сценария: единый проход regex (`СЦ. N` → `N-1`), затем подпадывание двух разрядов — чтобы избежать двойного декремента при последовательных заменах.
- **basePath для кастомного домена:** в workflow добавлена проверка `public/CNAME` — если CNAME есть, `NEXT_PUBLIC_BASE_PATH` пуст (корень), иначе используется логика по имени репо. После фикса все ассеты ссылаются на корень домена. Коммит `1c3a25c`.
