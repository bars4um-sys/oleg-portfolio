# Бренд «Студия 40» — знак и связки

Исходники фирменного знака (монограмма **ЧО** — Чумаченко Олег) и генераторы растровых ассетов.
Папка вне сборки: Next.js её не компилирует, в `out/` она не попадает. Итоговые файлы лежат в `public/`.

## Что здесь

| Файл | Что это |
| --- | --- |
| `mark.svg` | Знак в графите (`#1F1F1F`), сетка `0 0 480 260` |
| `mark-small.svg` | Тот же знак с утолщённым контуром (`stroke-width="8"`) — для малых размеров |
| `lockups.html` | Превью связок + шапки + иконок (открыть в браузере) |
| `build-lockups.py` | Генератор `lockups.html` |
| `build-icons.py` | Генератор `public/icon.svg`, `icon-*-32x32.png`, `apple-icon.png`, `favicon.ico` |
| `build-og.py` | Генератор `public/og-preview.jpg` (1200×630) |

## Геометрия

Знак собран по листу 01 брендбука: сетка 480×260, вертикали 42/46, горизонтали 10,
скругления 59.5 и 39. Сверка с мокапом по пикселям — IoU 0.91.

## Связки

- **Вертикальная (основной логотип, лист 02 №01):** «С Т У Д И Я» сверху, растянуто по ширине знака;
  знак ЧО снизу. Кегль надписи = 0.272 высоты знака, отбивка = 0.145 высоты знака.
- **Горизонтальная (лист 02 №02/№03, резерв):** «С Т У Д И Я» слева, знак ЧО справа,
  выровнен по нижней границе. Кегль надписи = 0.875 высоты знака, отбивка = 0.6 высоты знака.

Реализация в коде: `components/brand/mark.tsx` (сам знак) и `components/brand/lockup.tsx` (связки).
Все размеры выводятся из одной величины — высоты знака.

## Как пересобрать ассеты

Нужен macOS + Google Chrome (растеризация SVG/HTML через `chrome --headless --screenshot`)
и Python 3 с Pillow.

```bash
python3 brand/build-lockups.py   # → brand/lockups.html
python3 brand/build-icons.py     # → public/icon.svg, icon-*-32x32.png, apple-icon.png, favicon.ico
python3 brand/build-og.py        # → public/og-preview.jpg
```
