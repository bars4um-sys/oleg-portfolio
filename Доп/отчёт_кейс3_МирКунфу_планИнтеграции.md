- Структура архива (распаковать во временную папку):
  - `app/page.tsx` → рендерит `<CaseStudyPage />`.
  - `components/case-study/case-study-page.tsx` — **нарративная страница кейса** (клиентский компонент, `'use client'`, `IntersectionObserver`, sticky-навигация). - **Шрифты кейса:** `Fraunces` (display, italic, subsets latin+cyrillic-ext, веса 400/500/600), `Geist` (body, latin+cyrillic-ext), `Noto_Serif_SC` (идеограммы 功夫, chinese-simplified, 400). 3. Догрузить шрифты в корневой `app/layout.tsx`:
   - `Geist({ subsets: ['latin','cyrillic-ext'], variable: '--font-body' })`
   - `Noto_Serif_SC({ subsets: ['chinese-simplified'], weight: ['400'], variable: '--font-cjk' })`

4. В `app/globals.css`:
   - добавить `--font-display: var(--font-display-kunfu);` в **не-инлайновый** блок `@theme` (чтобы сгенерировался утилитарный класс `font-display`);

5. Перенести **только** `case-study-page.tsx` в `components/case-study/kunfu/case-study-page.tsx` (слайды и питч-дек НЕ переносить). Импортов `@/...` у него нет (использует только `react`), переписывать импорты не потребуется.
6. Создать маршрут `app/kunfu/page.tsx`:
